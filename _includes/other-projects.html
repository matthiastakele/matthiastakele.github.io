Albie (Personal Project)

Designing, building, and shipping an iOS app for collaborative photo albums, journaling, and messaging — solo, end to end. Built the React Native/Expo client and a TypeScript/Node and PostgreSQL backend with Redis, Cloudflare R2, and Socket.IO for real-time collaboration. Implemented resumable media uploads and offline sync using durable queues, multipart transfers that survive app termination, and idempotent APIs. Added semantic photo search and Ask Albie, an on-device AI assistant built on image-text embeddings and local LLMs with structured outputs and response validation, written as custom Swift modules so no photo ever leaves the phone.

React Native/Expo TypeScript Node.js PostgreSQL Redis Swift Core ML Socket.IO Cloudflare R2
